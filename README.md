#  CineLux - Event Booking System

A modern and responsive **Event Booking System** built with **React.js** and **Tailwind CSS**. CineLux allows users to explore luxury events, view event details, and book premium experiences through an elegant and user-friendly interface.

---

## 📖 Project Overview

CineLux is designed to provide a premium event booking experience with a modern UI inspired by luxury brands. Users can browse different event categories, view detailed event information, and make bookings through an intuitive interface.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/CineLux-Event-Booking-System.git
```

### Navigate to the project

```bash
cd frontend
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
